# CS 1.6 SCP Models

Counter-Strike 1.6 (GoldSrc HLMDL v10) SCP player models, viewmodels (`v_`), player weapon models (`p_`), and world models (`w_`).

> Only `.mdl` files are included — no source code, no facility/map models, and no `.bz2`/`.ztmp` cache files.

## Structure

- `models/player/scp*/` — SCP & human role player models (SCP-049, 066, 076, 096, 106, 173, 939, Class-D, Scientist, Security, MTF/MOG, Chaos Insurgency, Serpent's Hand, Zombie variants)
- `models/scp/` — Custom SCP viewmodels, p-models & w-models (SCP-076 blades/daggers, SCP-096 claws, Serpent's Hand weapon viewmodels)
- `models/next21_scp/` — SCP weapon & item viewmodels / p-models / w-models (keycard, crowbar, fists, HK416, MP5, TAR-21, UTS-15, pistol, revolver, injector, radio, SCP hands)
- `models/scp_cs/` — `v_scp-173.mdl`
- `models/scpcb/` — SCP armor p-models & w-models (`p_scp_armor_v1/v2.mdl`, `w_scp_armor_v1/v2.mdl`)
